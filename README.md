# Semantic Search Engine (Elasticsearch + NLP)

A basic semantic search engine built using:
- Python
- Elasticsearch
- Sentence Transformers
- Pandas

## Features
- Indexes product catalog data
- Performs semantic search over product descriptions
- Returns relevant products based on meaning, not keywords
